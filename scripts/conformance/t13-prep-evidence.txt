## RUN 5 · ASSERT 层复核（captain 指派，发现 5 处并全堵）
  复核方法：用审别人的敌意审自己上轮刚写的代码（谓词逐条问"两侧各以什么错法
  能同过这条"）。发现与处置：
  ① eq 泛比较放行 Python True==1 → candidate 把 1 写成 true 假绿。
     治：eq_strict（bool 与数字永不互判）；哨兵 assert-eq-strict-bool-vs-int：
       {count:true} eq 1 → 红 ✓；{count:1} eq 1 → 绿 ✓；{count:true} eq true → 绿 ✓
  ② 共享数据源（Go 误连生产库）时 lifecycle 两侧各自看对侧假号而全绿。
     治：find_by_prefix_missing({{OTHER}} 前缀) + 自动变量 SAME_SOURCE；
       同源自比如实 skip（unless_shared_source，承认无证据非伪造绿——
       本轮 lifecycle 自测报告里该探测即显示 skip，属预期）；跨服务强制生效。
     哨兵 assert-shared-source-contamination-detect：污染红/干净绿/同源 skip 三态 ✓
  ③ asserts:[] 空清单静默跳过 = 伪装已覆盖。治：键存在即判，空清单红。
  ④ mutating 重试重放写序列 → 二次 create 去重漂移 + 失败留残留。
     治：mutating 强制 retries=0。实证：本轮 lifecycle flaky=0（上轮曾 flaky=1）。
  ⑤ 谓词值全部有实测来源标注（含 GW-models pin 凭印象被实测纠正的反面留痕）。
  回归：引擎 51/51；live safe 41/41；lifecycle 实弹 PASS + 残留零（独立 curl 复测）。
