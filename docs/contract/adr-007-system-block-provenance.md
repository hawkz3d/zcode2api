# ADR-007 · `zcode_system.json`（官方身份块）的定性与使用

- 状态：**已裁定**（2026-10-15）
- 裁定人：用户
- 相关：`adr-006-frontend-rewrite.md`、`endpoints.md` §A-03

## 决策

`internal/gateway/zcode_system.json` **内置在仓库中，原样使用**。

## 这个文件是什么

| 项 | 值 |
|---|---|
| 文件 | `internal/gateway/zcode_system.json`（1763 字节） |
| 内容 | Anthropic `system` 数组的 3 条身份块文本：① `You are ZCode, an interactive coding agent`（42 字符）② 1211 字符的详细提示词 ③ 187 字符的环境说明 |
| 敏感信息 | 无（形态扫描 0 命中） |
| 放置契约 | `endpoints.md` §A-03：映射为 Anthropic `system` 数组的**末位**元素 |

## 为什么必须内置

单变量对照实测（2026-09-30，可复现）：

| 变量 | 结果 |
|---|---|
| 原始 body（无身份块） | 🔴 **405 / 3012**「request has been blocked due to unusual activity」 |
| 仅加身份块（其余不变） | ✅ **200 通过** |
| 仅加 `metadata.user_id` | 🔴 405 |
| 仅加 `cache_control` | 🔴 405 |
| 头部任意变化（裸头 / 全量身份头 / 追踪头） | 🔴 全部 405 |

**身份块是唯一开关**：没有它，`zai-jwt` / `start-plan` 通道完全不可用。

## 定性：协议数据，不是实现代码

| 判据 | 身份块文本 |
|---|---|
| 是算法 / 代码逻辑吗 | ❌ 它是数据（提示词文本） |
| 是上游要求的协议内容吗 | ✅ 服务端内容审查依据它放行 |
| 有替代实现吗 | ❌ 内容由上游定义，无法\"重写\" |
| 是某个实现者的创造性成果吗 | ❌ 它是官方客户端发往其自家服务端的文本 |
| 照抄会继承他人的表达吗 | 极弱：功能上等同协议常量（如 User-Agent 字符串） |

**同类对比**：

| 资产 | 性质 | 处置 |
|---|---|---|
| `zcode_system.json` 身份块 | 上游协议数据（服务端验收依据，无替代实现） | **原样使用** |
| `captcha_node/solver.js`（1748 行） | 第三方实现（有独立算法逻辑） | 作为外部黑盒进程调用，见 ADR-009 |
| `frontend/` 页面 | 第三方实现（有表达性与结构性） | 重写，保结构等价，见 ADR-006 |

## 判据（写入决策原则）

> 判断一个外部资产如何使用，看它的**性质**：
> - **外部实现**（算法 / 代码 / 结构性表达）→ 重写或替换
> - **上游的协议数据**（服务端验收依据、无替代实现）→ 原样使用

`endpoints.md` 记录放置位置（行为契约），本文件承载具体文本（协议数据）。两者职责分离：
位置由契约约束、内容由上游定义。
