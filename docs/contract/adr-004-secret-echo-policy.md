# ADR-004 · 密钥回显端点的处置政策

- 状态：**已裁定**（2026-10-15）
- 裁定人：captain（Euphelia）
- 触发：①Hilkiah 契约文档 CR-05 记录该行为；②t4 成员探索期因调用该端点导致有效 key 进入会话（已轮换作废）

## 现象（实测）

`GET /admin/api/settings` 返回：

```json
{"admin_key":"<32 字符明文>","gateway_key":"","quota_refresh_interval":600}
```

**该端点明文回显管理凭证本身**。任何持有管理凭证者可读回密钥。

## 裁定

### 1. 本次等价重写**照抄该行为**（契约等价优先）

理由：
- 对拍 L2/L3 会逐字段比对，若新服务"顺手修掉"（不返回 `admin_key`）→ **字段缺失 → 对拍必挂**
- 本次目标是**等价替换**，不是安全加固；改变行为会使"等价"无法证明
- CR-05 已在契约文档中标注为**已知安全问题**，风险被显式记录而非隐藏

### 2. 但必须同时做三件缓解（不得省略）

1. **文档标注**：`endpoints.md` / `compat-risks.md` 已标注（Hilkiah 已完成）
2. **工具脱敏**：对拍器与一切内部工具在**读取该端点响应时必须默认脱敏**（Liche 的 harness 已要求加硬防线）
3. **纪律约束**：任何成员**不得**把该端点响应的原文贴进会话/文档/提交

### 3. 密钥轮换原则（本次已两次触发）

- **凡有明文进入会话上下文，即视同泄漏，无条件轮换**——因为会话记录会持久化，无法收回
- 本次已轮换两次：
  - 第 1 次：captain 早前验证 SQLite 读取时误打印 `meta` 表内容
  - 第 2 次：t4 成员探索期调用 `/admin/api/settings`
- 轮换后必须实测：新 key 200 / 旧 key 401，并复验 3 个消费方（cron ×2、`dsh-zcode-connect`）

### 4. 后续（非本次范围）

若要修复该安全问题（不回显密钥），属**独立增强需求**：
- 需另立 ADR + 对拍豁免条目（X-4）
- 且应同时提供"密钥读取"的替代通道（否则前端设置页会失效）
- **不在本次等价重写内实施**

## 附：一条方法论（Hilkiah 提出，captain 采纳）

**凭证轮换后，泄漏自检必须改用「形态扫描」重跑**，不能再用"拿 `.env` 当前值反查"——
因为旧值已不在 `.env` 里，反查法对"轮换前落盘的旧值"失效。

形态扫描判据（不依赖任何当前值）：
- JWT 三段式：`eyJ…\.eyJ…\.[A-Za-z0-9_-]+`
- 智谱 apiKey 形态：`[a-f0-9]{32}\.[A-Za-z0-9]{16,}`
- `Bearer` 长串
- 敏感字段名的**非占位**取值（`<redacted>` / `<fake>` / 空 之外）

此判据已写入对拍验收常规动作。

### 补正二：形态集必须覆盖被扫对象自身的产物类型（2026-10-15，实际踩中）

**事故**：t2 交付的自检报告「0 命中」，但 `captcha-spike.md` 实际含一行**未打码的真实 securityToken 样本**。

**根因**：t2 的形态集是 `Bearer / eyJ / password / api_key` —— 全部是**通用凭证形态**，
**不含本主题自身的产物形态**（阿里云验证码的 base64 长串 + `|` 分隔结构）。
于是「0 命中」是**判据不完整导致的假阴性**，不是谎报。

**判据（强制执行）**：做泄漏自检时，形态集**必须**包含：
1. 通用凭证形态（JWT 三段式 / 32hex / `32hex.16char` / `Bearer` 长串 / `sk-` 前缀）
2. **本次任务的产物形态**——凡本次研究涉及的令牌/密钥/指纹/签名产物，其**字面形态**必须进形态集
   - 例：验证码 `VERIFY_PARAM=` 后接的 base64（≥100 字符）
   - 例：`base64|base64` 的分隔结构
   - 例：本次涉及的任何私有协议字段的取值形态
3. **敏感字段名的非占位取值** —— 且占位符的识别必须显式定义（排除 `<...>` 包裹串，
   否则「描述性占位文本」会被反复误报为真值）

**两条方法论必须配对使用**：
- 补正一（轮换后用形态扫描）解决「**用当前值反查会漏旧值**」
- 补正二（形态集覆盖自身产物）解决「**形态集不全会漏本主题产物**」
- 只做其中一条，仍会漏。

**已知的残留暴露面（本 ADR 确认，非仓库内容）**：
`workspace/temp/` 下曾有 9 个文件含**完整** VERIFY_PARAM（含完整 128 字符 securityToken）：
`solver_out.txt`、`strace_write.txt`、`diag*.json`、`vt_*.json`。
已移入权威凭据隔离区 `/opt/appdata/cred-archive/captcha-tokens-20261015/`（700/600）。
**`workspace/` 非 git 仓库**，故这些文件从未入库；但作为「活的完整令牌」，仍按凭据管理。
